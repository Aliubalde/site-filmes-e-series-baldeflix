# BALDÉ FLIX

Este projeto contém a versão PHP + MySQL da BALDÉ FLIX, preparada para XAMPP. Os ficheiros do site estão em [`xampp/`](./xampp/).

## Executar localmente

1. Copie a pasta `xampp` para `C:\xampp\htdocs\balde-flix`.
2. Inicie Apache e MySQL no XAMPP Control Panel.
3. Configure `config.php` e a base de dados conforme [`xampp/README.md`](./xampp/README.md).
4. Abra `http://localhost/balde-flix/`.

A pasta `C:\xampp\htdocs\balde-flix` é a instalação executada pelo Apache. O código-fonte deste projeto está em `xampp/`; alterações só chegam à instalação depois de copiar os ficheiros.
